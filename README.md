# 🍜 Idiyappam Order Management App (இடியாப்பம் ஆர்டர் செயலி)

A simple and efficient native Android application designed for managing daily homemade Idiyappam orders. Built with Java and XML for the Android front-end, integrated with Google Firebase as the real-time cloud backend.

## 📱 Features

* **Bilingual UI:** Clean, dark-themed user interface presented in both Tamil and English[span_0](start_span)[span_0](end_span).
* **Order Placement:** Customers can enter their Name, Quantity, and Delivery Address[span_1](start_span)[span_1](end_span).
* **Form Validation:** In-built field check alerts with Toast warnings when mandatory details are left empty[span_2](start_span)[span_2](end_span).
* **Firebase Cloud Storage:** Real-time persistence of order records directly to Firebase.
* **Order History / Listing:** Quick retrieval option to view all past and pending customer orders[span_3](start_span)[span_3](end_span).
