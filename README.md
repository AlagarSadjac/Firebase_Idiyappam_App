## 📱 About The App
This app automates and streamlines order collection for a local homemade food business. It replaces manual order taking by capturing essential customer details and saving orders instantaneously into Firebase Cloud, preventing lost records and simplifying daily order processing.

---

## ✨ Features
* 🌐 **Bilingual User Interface:** Clean, dark-themed UI presented in both Tamil and English for easy usability.
* 📝 **Instant Order Placement:** Customers can input their Name, Order Quantity, and Delivery Address.
* ⚠️ **Form Validation:** Integrated input validation checks with immediate alerts when mandatory fields are omitted.
* ☁️ **Real-time Firebase Cloud Storage:** Live synchronization and persistence of order data directly in Firebase.
* 📋 **Order History & Retrieval:** Easy listing view to inspect pending and processed daily orders.

## 🚀 How To Use
1. Download and install the APK via the download badge above.
2. Launch the app and enter customer details (Name, Quantity, and Delivery Address).
3. Submit the order to sync it immediately to the cloud database.
4. Review saved records anytime via the order listing interface.

---

## 🎯 Purpose
The main goal of this application is to digitize daily local business operations using modern Android development practices combined with Firebase serverless infrastructure, ensuring zero order loss and rapid tracking.
